# i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add PT/EN subpath routing (`/pt`, `/en`) to the Next.js 14 portfolio using `next-intl`, translating all UI labels and structured content (projects + timeline).

**Architecture:** `next-intl` middleware detects `Accept-Language` and redirects `/` to `/pt` or `/en`. All pages move to `app/[locale]/`. UI strings live in `messages/pt.json` + `messages/en.json`; complex structured data (projectData, timelineData) lives in `constants/data/pt.tsx` + `constants/data/en.tsx` and is passed as props down to components.

**Tech Stack:** Next.js 14.2.2 App Router, next-intl v3, TypeScript, Tailwind CSS

## Global Constraints

- Locales: `["pt", "en"]`, default locale: `"pt"`
- Section HTML `id` attributes stay in English (`About`, `Projects`, `Services`) — only display labels are translated
- `next.config.mjs` uses ESM (`export default`) — keep that format
- No test framework — verify with `npx tsc --noEmit` and manual browser checks
- Do not add `"use client"` to any currently-server component unless required

```ts
import { defineRouting } from 'next-intl/routing';
import { createNavigation } from 'next-intl/navigation';

export const routing = defineRouting({
  locales: ['pt', 'en'],
  defaultLocale: 'pt',
});

export type Locale = (typeof routing.locales)[number];

export const { Link, redirect, usePathname, useRouter } = createNavigation(routing);
```

- [ ] **Step 4: Create `i18n/request.ts`**

```ts
import { getRequestConfig } from 'next-intl/server';
import { routing } from './routing';

export default getRequestConfig(async ({ requestLocale }) => {
  let locale = await requestLocale;

  if (!locale || !routing.locales.includes(locale as Locale)) {
    locale = routing.defaultLocale;
  }

  return {
    locale,
    messages: (await import(`../messages/${locale}.json`)).default,
  };
});

type Locale = (typeof routing.locales)[number];
```

```tsx
'use client';

import { useLocale } from 'next-intl';
import { usePathname, useRouter } from '@/i18n/routing';
import { cn } from '@/lib/utils';

export default function LocaleSwitcher() {
  const locale = useLocale();
  const router = useRouter();
  const pathname = usePathname();

  const switchLocale = (newLocale: 'pt' | 'en') => {
    router.replace(pathname, { locale: newLocale });
  };

  return (
    <div className="flex gap-1 text-sm font-medium">
      <button
        onClick={() => switchLocale('pt')}
        className={cn(
          'transition-colors',
          locale === 'pt' ? 'text-blue-500 font-bold' : 'text-slate-400 hover:text-white'
        )}
      >
        PT
      </button>
      <span className="text-slate-500">|</span>
      <button
        onClick={() => switchLocale('en')}
        className={cn(
          'transition-colors',
          locale === 'en' ? 'text-blue-500 font-bold' : 'text-slate-400 hover:text-white'
        )}
      >
        EN
      </button>
    </div>
  );
}
```
